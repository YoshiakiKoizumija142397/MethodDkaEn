# MethodDkaEn (200th-degree Polynomial Solver & Factorization Web App with 50-digit Precision)

*MethodDkaEn* is a lightweight, ultra-fast, and high-precision web application for solving polynomials and performing factorization using pure HTML and JavaScript. 

Powered by the Durand-Kerner (DKA) method, it combines **50-digit high-precision arithmetic** via Decimal.js, **auto-scaling normalization for up to 200th-degree polynomials**, and a convenient **bulk coefficient pasting feature** into an all-in-one package.

---

## 📝 Key Features

1. **📋 Bulk Coefficient Input**
   - Easily paste space, line-break, or comma-separated values (e.g., `1 -55 1320 -18150 ...`) to populate all coefficient input fields in a single click.

2. **⚡ Auto-Scaling for High-Degree Polynomials (Up to Degree 200)**
   - Prevents overflow and underflow even when dealing with extremely large or tiny coefficients, enabling stable execution across high-degree computations.

3. **🎯 50-Digit Precision & Instant Mode Switching**
   - Seamlessly toggle between "50-Digit High-Precision Roots" and "Factored Form (rounded to 1 decimal place)" without re-triggering computation.

4. **🌐 Fully Multi-Platform & Offline Support**
   - Runs locally in any modern web browser (Chrome, Edge, Safari, Firefox, etc.) across Windows, Mac, Linux, iOS, Android, and ChromeOS without needing a backend server.
